# Bioinformatics Projects 🧬💻

A growing collection of Python tools that apply computer science to
biological problems — from DNA sequence analysis to nucleotide
visualization with BioPython and Matplotlib.

## 📂 Projects

| Project | Description | Status |
|---|---|---|
| [GC Content Analyzer](./gc-content-analyzer) | Validates a DNA sequence and calculates/classifies its GC content | ✅ Complete |
| [DNA Sequence Analyzer](./dna-sequence-analyzer) | Nucleotide composition, GC/AT content, complementary strand, reverse complement | ✅ Complete |
| [BioSequence Visualizer](./biosequence-visualizer) | Object-Oriented DNA analyzer with Matplotlib nucleotide distribution & GC/AT ratio charts | ✅ Complete |
| Gene Expression Visualizer | Visualizing gene expression data from NCBI datasets using Pandas and Matplotlib | 🚧 In Progress |
| COVID Genome Analyzer | Parsing and analyzing SARS-CoV-2 genome data with BioPython | 🚧 Planned |

Each project lives in its own folder with its own detailed README,
example usage, and sample output.

## 🚀 Quick Start

```bash
git clone https://github.com/harshwardhan-bio/bioinformatics-projects.git
cd bioinformatics-projects
pip install -r requirements.txt
```

Then navigate to any project folder and run its script:

```bash
cd biosequence-visualizer
python biosequence.py
```
